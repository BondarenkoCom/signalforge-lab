# Pilot Offer

SignalForge sells a narrow planning deliverable for authorized security review, not exploitation.

## Offers

| Tier | Budget Filter | Output |
| --- | ---: | --- |
| Free sanity check | `$0` | High-level queue from one public-safe scope note. |
| Quick triage | `$49-$99` | Two or three highest-signal checks, boundary notes, and safe proof guidance. |
| Review plan | `$150-$300` | Control model, authorization matrix, prioritized queue, report skeleton, and validation notes. |

## Acceptance

Accept only when the request includes:

- clear authorization or safe-harbor reference;
- public-safe scope summary;
- roles, objects, routes, interfaces, or workflows;
- explicit out-of-scope constraints;
- a useful deliverable that can be produced without unsafe target testing.

Reject when the request asks for stealth, spam, social engineering, credential attacks, denial of service, persistence, third-party data access, or secrets in public intake.
